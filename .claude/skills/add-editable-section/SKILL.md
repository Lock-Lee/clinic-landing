# เพิ่มส่วนที่แก้ได้ในหลังบ้าน

ส่วนที่แก้ได้ = key หนึ่งตัวใน `editableDefaults` ชื่อเดียวกันใช้ทั้งเป็น id แท็บในหลังบ้าน และชื่อสิทธิ์ใน `PLAN_SECTIONS` ต้องตรงกันทุกที่ ไม่งั้นแท็บจะล็อกผิดหรือบันทึกไม่ลง

## 1. ตัดสินใจก่อน (ถามผู้ใช้ถ้าไม่ชัด)

- ชื่อ key ภาษาอังกฤษสั้นๆ เช่น `doctors`, `faqs`, `gallery`
- แพ็กไหนแก้ได้ (ดู `docs/business.md`) ถ้าเปลี่ยนสิ่งที่แต่ละแพ็กได้ ต้องแก้ `docs/business.md` และข้อความการ์ดราคาใน `apps/landing/app/content.ts` ด้วย
- แม่แบบไหนมีส่วนนี้ (บางส่วนมีแค่ Premium)

## 2. ไล่แก้ให้ครบ

1. **สิทธิ์:** `packages/db/src/plans.ts` เพิ่ม key ในแพ็กที่ได้ (แพ็กสูงกว่าได้ด้วยเสมอ)
2. **เนื้อหา:** `apps/<แม่แบบ>/app/content.ts` ใส่ key ใน `editableDefaults` (ค่าเริ่มต้นสมมติ)
3. **หน้าเว็บ:** ทุกหน้าที่แสดงส่วนนี้อ่านจาก `getContent(...)` ไม่ใช่ import ตรงจาก content.ts ใช้ index เป็น key ของ list (ชื่อแก้ได้ อาจซ้ำ) กรองรายการว่าง
4. **editor:** `app/admin/editor.tsx` เพิ่ม section `{ id: "<key>", label: "<ไทย>" }` ใช้ `ListEditor`, `TextField`, `ImageField` จาก `@repo/ui/admin` รูปต้องผ่าน `ImageField` (อัปโหลดเข้า S3) ห้ามเก็บ data URL
5. **ตรวจค่าก่อนบันทึก** ถ้ามีกติกา (slug ไม่ซ้ำ ลิงก์ถูกรูปแบบ) แบบเดียวกับบริการ/บทความใน `apps/clinic-full-demo/app/admin/editor.tsx`
6. **admin กลาง** ใช้ editor เดียวกันอยู่แล้ว ไม่ต้องแก้ ถ้าเพิ่ม key ใหม่ใน plans แล้ว แท็บจะล็อกให้แพ็กที่ไม่มีสิทธิ์เอง

## 3. ตรวจ

1. `bun run typecheck`
2. เพิ่มเทสต์ใน `e2e/tests/demo-admin.spec.ts`: แก้แล้วหน้าเว็บเปลี่ยน และ (ถ้าแพ็กต่ำกว่าไม่มีสิทธิ์) API ของแพ็กต่ำไม่บันทึก key นี้ ใน `central-admin.spec.ts`: ลดแพ็กแล้วแท็บนี้ล็อก
3. `bun run test:e2e` ผ่านทั้งหมด และหน้า 375px ไม่เลื่อนแนวนอน
4. อัปเดตรายการสิทธิ์ใน `docs/architecture.md` และ `docs/business.md`
