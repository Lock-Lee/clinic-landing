# ธุรกิจรับทำเว็บ (hamcache): ข้อตกลงที่ใช้อยู่

ไฟล์นี้บันทึกสิ่งที่ตัดสินใจไปแล้ว ราคาและข้อความบนเว็บขายดึงจาก `apps/landing/app/content.ts` ถ้าแก้ราคาที่นั่น ให้แก้ไฟล์นี้ด้วย
อัปเดตล่าสุด: 9 ต.ค. 2026

## ตำแหน่งของบริการ

- หัวเว็บขาย: "รับทำเว็บไซต์และ Landing Page ทุกธุรกิจ" (เปลี่ยนจากเฉพาะคลินิกความงามเมื่อ 9 ต.ค. 2026 ราคาและแพ็กเกจเท่าเดิม)
- กลุ่มลูกค้า: ทุกธุรกิจ เช่น ร้านค้า ร้านอาหาร คาเฟ่ คลินิก สปา โรงแรม บริษัท แต่เว็บตัวอย่างและระบบหลังบ้านตอนนี้ยังทำมาสำหรับคลินิก
- Starter และ Standard = Landing Page หน้าเดียว (เป้าหมายเดียว: ให้คนทัก LINE โทร จอง หรือสั่งซื้อ ใช้คู่โฆษณา)
- Premium = เว็บไซต์หลายหน้า (หน้าบริการแยก บทความ หลายภาษา) แบบเว็บไซต์เต็มรูปแบบ
- เว็บตัวอย่างทุกตัวมีหลังบ้านตัวอย่างที่ `/admin` ให้ลูกค้าลองแก้เอง (Starter แสดงเป็นส่วนเสริม +3,900)
- แต่ละแพ็กมีเว็บตัวอย่างให้ลูกค้ากดดูจากการ์ดราคา: Starter = `clinic-starter-demo`, Standard = `clinic-demo`, Premium = `clinic-full-demo`
- เว็บอ้างอิงที่ลูกค้ามักส่งมา (เช่น เว็บคลินิกหลายหน้า) ส่วนใหญ่อยู่ระดับ Premium ต้องบอกลูกค้าให้ชัดก่อนเสนอราคา

## แพ็กเกจ (จ่ายครั้งเดียว ไม่รวมโดเมน โฮสติ้ง MA)

| แพ็กเกจ | ประเภท | ราคา (บาท) | แก้งาน | ส่งงาน | ดูแลฟรี |
| --- | --- | --- | --- | --- | --- |
| Starter | Landing Page หน้าเดียว | 12,000 | 2 รอบ | 5-7 วัน | 1 เดือน |
| Standard | Landing Page หน้าเดียว | 22,000 | 3 รอบ | 10-14 วัน | 2 เดือน |
| Premium | เว็บไซต์หลายหน้า (5-7 หน้า) | 42,000 | 5 รอบ | 21-30 วัน | 3 เดือน |

สิ่งที่แต่ละแพ็กเกจได้เพิ่ม:
- **Starter:** เทมเพลต 5-6 section, ปุ่ม LINE/โทร/แผนที่, SEO พื้นฐาน (title, description, sitemap, Search Console)
- **Standard:** ดีไซน์เฉพาะแบรนด์ 8-10 section, ระบบหลังบ้าน (แก้ข้อความ อัปโหลดรูป โปรโมชัน รีวิว), ฟอร์มจองแจ้งเตือนเข้า LINE, ตั้งค่า LINE OA, Pixel + GA4, SEO + AEO (FAQ + Schema)
- **Premium:** ระบบหลังบ้านเต็มรูปแบบ, จองคิวในแอป LINE + เตือนนัด, SEO + AEO รายหน้า, 2 ภาษา

## เงื่อนไข

- มัดจำ 50% ก่อนเริ่มงาน ส่วนที่เหลือชำระก่อนขึ้นเว็บจริง
- **แก้งานเกินรอบ = CR (Change Request)** คิดราคาตามเนื้องานจริง แจ้งราคาให้ลูกค้ายืนยันก่อนเริ่มทุกครั้ง
- งานเพิ่ม: section ละ 1,500 บาท, หน้าละ 3,000 บาท, ระบบหลังบ้านสำหรับ Starter 3,900 บาท

## หลังบ้านและ admin กลาง (เดโม ต.ค. 2026)

- คลินิกทุกรายแก้เว็บผ่าน admin กลางที่เดียว login ด้วยบัญชีของตัวเอง เห็นเฉพาะเว็บของตัวเอง ทีมเราเห็นทุกคลินิก
- สิทธิ์ตามแพ็กเกจ: Starter + หลังบ้าน (+3,900) แก้ข้อมูลคลินิก หน้าแรก บริการและราคา / Standard เพิ่มโปรโมชัน รีวิว / Premium เพิ่มบทความ (ใส่รูปในบทความได้) และเมนู/เมนูย่อย
- ส่วนที่แพ็กไม่ครอบคลุมแสดงเป็นแท็บล็อก "มีในแพ็กเกจ …" ใช้ชวนอัปเกรด
- เว็บคลินิกแต่ละรายใช้โดเมนของคลินิกเอง ระบบกลางเป็นแค่ที่เก็บเนื้อหาและรูป
- ต้องตกลงก่อนขายจริง: ถ้าเลิกใช้ระบบเรา จะส่งออกเนื้อหาและรูปให้ หรือส่งมอบเว็บแบบแยก (ไม่ขัดกับ "ย้ายออกได้ทุกเมื่อ") / ค่าเซิร์ฟเวอร์กลางคิดรวมใน MA / ระบบเก็บข้อมูลคลินิก ต้องดู PDPA
- ยังเป็นเดโม: ไม่มีลืมรหัสผ่าน ไม่มีประวัติการแก้ไข ไม่มี cache กันเว็บคลินิกล่มตอนฐานข้อมูลล่ม

| รายการ | ราคาบนเว็บ | ที่มา |
| --- | --- | --- |
| .com | เริ่ม 519 บาท/ปี | ราคาต่ออายุ Hostinger |
| .co.th | เริ่ม 856 บาท/ปี | THNIC (ต้องเป็นนิติบุคคล) |

- จดโดเมนในชื่อคลินิกเอง ย้ายออกได้ทุกเมื่อ
- ยังไม่ได้ยืนยันว่าราคาเหล่านี้รวม VAT หรือไม่

| Standard | 1,500 บาท/เดือน | แก้ข้อความ รูป โปรโมชัน 4 ครั้ง/เดือน |

## LINE OA

- Starter ลิงก์ไป LINE OA, Standard ตั้งค่า OA + ฟอร์มจองแจ้งเตือนเข้า LINE, Premium จองคิวในแอป LINE (LIFF) + ยืนยัน/เตือนนัด
- บริการเสริม: ตั้งค่า LINE OA + Rich Menu แยก (ไม่ทำเว็บ) เริ่ม 3,900 บาท (ตัวเลขตั้งไว้ก่อน ยังไม่ได้ยืนยัน)
- บัญชี OA เป็นชื่อคลินิก เราเป็นแอดมินร่วม
- ค่าส่งข้อความเกินโควตาฟรี (push) คลินิกจ่าย LINE เอง ข้อความตอบกลับไม่เสียเงิน
- แจ้งเตือนต้องใช้ LINE Messaging API (LINE Notify ปิดบริการแล้ว)
- ตอนนี้มีแค่แชทจำลองไว้โชว์ (`LineChatMock`) ยังไม่ได้ต่อ API จริง

## SEO / AEO

- SEO: title, description, canonical, Open Graph, sitemap, robots
- AEO: FAQ บนหน้าเว็บ + FAQPage Schema และ Schema ธุรกิจ (MedicalClinic / ProfessionalService) ให้ Google และ AI ดึงไปตอบได้
- robots เปิดให้ AI crawler อ่าน

## กฎหมายและความเสี่ยง

- ธุรกิจที่มีกฎโฆษณาเฉพาะ: คลินิกตามเกณฑ์ สบส., อาหาร/เครื่องสำอางตาม อย. เจ้าของธุรกิจเป็นผู้ขออนุมัติโฆษณา เราช่วยจัดเนื้อหาได้
- ฟอร์มที่เก็บชื่อและเบอร์ต้องมีช่องยินยอมตาม PDPA
- เว็บเดโมทุกตัวใช้ชื่อและข้อมูลสมมติ ห้ามคัดลอกชื่อ โลโก้ ข้อความ หรือรูปของธุรกิจจริงที่ไม่ใช่ลูกค้าของเรา
